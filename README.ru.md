# conatus

[English](README.md) · **Русский** · [Українська](README.uk.md)

Маленький бот SimpleX Chat для читательской группы: он **хранит каждый файл,
которым делится группа**, **возвращает его по слову** и **проводит голосования
реакциями**. И ничего больше. Node >= 22, без npm-зависимостей, на своём сервере.

Сделан для книжных клубов и учебных кружков. Кто-то выкладывает скан, запись,
раздаточный материал; через три месяца любой получает его обратно, ответив на тот
пост одним словом, вместо того чтобы листать чат за год. Бот молчит, пока его не
спросят.

Нужно больше — карточки занятий, расписание, напоминания, «Этика» Спинозы? Его
старший брат [spinoza](https://github.com/liberbook/simplex-bot-for-philosophy-circle) умеет всё это на той же основе.

## Что он делает

В группе:

| что происходит | что делает бот |
| --- | --- |
| кто-то выкладывает файл | молча скачивает его в архив |
| кто-то удаляет свой пост с файлом для всех | переносит файл в `deleted/`, он стирается через 30 дней |
| `conatus` ответом на пост с файлом (или отдельным словом сразу под ним) | возвращает этот файл ответом |
| `/голосование Вопрос? \| Вариант 1 \| Вариант 2` | публикует одно сообщение; голосуют реакциями. Добавьте `несколько`, чтобы можно было выбрать несколько вариантов |
| автор удаляет свой пост `/голосование` | голосование исчезает вместе с сообщением бота |
| `/?` | краткая справка ответом |

Слово `conatus` внутри фразы, `голосование` без косой черты и всё остальное, что
говорят люди, бот не трогает: группа — это разговор людей. На любое личное
сообщение бот отвечает той же краткой справкой.

Всё, что он говорит, вместе с сообщением, которое это вызывает, — в
[INTERFACE.md](INTERFACE.md) (генерируется из кода, на английском). Заметки о
безопасности: [SECURITY.md](SECURITY.md).

## Запуск

```bash
git clone https://github.com/liberbook/simplex-bot-for-reading-circle.git conatus && cd conatus/deploy
mkdir -p data && cp ../conatus.example.json data/conatus.json   # группа, язык, лимит, слово
docker compose up -d --build
docker compose logs -f        # адрес бота: `address: https://…` (он же в data/state/address.txt)
```

Подключитесь к этому адресу из приложения SimpleX и пригласите бота в свою группу.
Он входит в любую группу, чьё имя подходит под `group` в настройках (или заходит
по ссылке из `groupLinks`). Ни администраторов, ни секретов: кто может пригласить
бота, тот и приглашает.

Чтобы бот говорил по-русски, укажите `"language": "ru"` в `conatus.json`.

Без Docker:

```bash
simplex-chat -p 5225 -d ./db/chat --files-folder ./files --temp-folder ./tmp -y \
    --create-bot-display-name conatus --create-bot-allow-files
node src/main.js --group "Книжный клуб"          # node src/main.js --help - все настройки
```

## Настройки

`conatus.json` рядом с ботом (или `--config`), переменные окружения `CONATUS_*`,
флаги командной строки; более поздний источник побеждает.

| ключ | по умолчанию | значение |
| --- | --- | --- |
| `group` | `*` | какие группы обслуживать (`*` — любой текст) |
| `groupLinks` | `[]` | ссылки на группы, в которые войти при запуске |
| `trigger` | `conatus` | слово, которым просят файл |
| `language` | `en` | `en`, `ru`, `uk`, `it` — язык всего, что говорит бот |
| `maxStorage` | `100gb` | лимит размера архива |
| `deletedRetentionDays` | `30` | сколько хранить файлы удалённых постов, `0` — всегда |
| `scan` | `100` | сколько последних сообщений перечитать при запуске, чтобы забрать пропущенные файлы |
| `server`, `dir`, `deletedDir`, `stateDir` | | адрес CLI и папки (в Docker заданы) |

## Перевод

Каждый текст лежит в маленьком файле на язык в [src/i18n/](src/i18n/), и это
просто данные — без кода и без знания о чате:

```js
noFileInPost: "There is no file in that post.",
whichFile: "Which file? Reply {trigger} to the post with the file.",
```

Чтобы добавить язык: скопируйте [src/i18n/en.js](src/i18n/en.js), переведите
значения, импортируйте файл в [src/i18n/languages.js](src/i18n/languages.js) и
добавьте его в таблицу там же. Это всё — `npm test` проверит ваш файл на
пропущенные ключи, лишние подстановки и командные слова, которые не разбираются.

Участники могут писать команду на **любом** из языков, каким бы ни был язык
группы: `/vote`, `/sondaggio`, `/голосование` и `/голосування` открывают голосование.

## Как он устроен

```text
src/main.js               точка сборки: создаёт объекты, больше ничего
src/config.js             настройки: по умолчанию < файл < окружение < флаги
src/transport/            протокол CLI: ChatConnection (WebSocket), SimplexClient (команды),
                          EventTranslator (JSON CLI -> события) - единственное место с полями CLI
src/domain/Command.js     чего просит сообщение в группе: /?, /vote, слово-триггер; остальное - разговор
src/domain/Poll.js        голосование как данные: разбор, бюллетени, подсчёт
src/domain/Message.js     одно нормализованное сообщение
src/storage/Folder.js     папка файлов (архив, удалённые): список, перенос, очистка по возрасту
src/storage/Outbox.js     копии отправляемых файлов, чтобы CLI не удалил оригинал из архива
src/storage/PollStore.js  голосования в одном JSON-файле
src/bot/Keeper.js         скачивает каждый файл, выносит файл удалённого поста, чистит
src/bot/Courier.js        возвращает файл по слову-триггеру
src/bot/Polls.js          голосования: сообщение, реакции, удаление
src/bot/Helper.js         справка
src/bot/Bot.js            направляет события, запускает всё вместе
src/i18n/                 каждый текст, по файлу на язык
```

Классы поведения получают шлюз и тексты через конструктор и не знают ни сокетов,
ни JSON; домен — чистые функции.

```bash
npm test                 # модульные тесты, node:test, ~1 с (вместо сети - поддельный шлюз)
npm run test:e2e         # весь сценарий в Docker (~3 мин): свои релеи, три пользователя, образ бота
npm run doc              # заново генерирует INTERFACE.md из кода
```

## Данные

```text
deploy/data/files/       архив (он же папка файлов CLI)
deploy/data/deleted/     файлы удалённых постов, 30 дней
deploy/data/state/       polls.json, address.txt
deploy/data/db/          база CLI: личность и ключи бота - не трогать
```

Начать заново: `docker compose down && sudo rm -rf data/{db,files,deleted,state,tmp} && docker compose up -d`
(новая личность — бота придётся пригласить снова).
