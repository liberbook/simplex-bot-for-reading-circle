# conatus

[English](README.md) · [Русский](README.ru.md) · **Українська**

Маленький бот SimpleX Chat для читацької групи: він **зберігає кожен файл, яким
ділиться група**, **повертає його за словом** і **проводить голосування
реакціями**. І нічого більше. Node >= 22, без npm-залежностей, на власному сервері.

Зроблений для книжкових клубів і навчальних гуртків. Хтось надсилає скан, запис,
роздатковий матеріал; через три місяці будь-хто отримує його назад, відповівши на
той допис одним словом, замість того щоб гортати чат за рік. Бот мовчить, доки
його не спитають.

Потрібно більше — картки занять, розклад, нагадування, «Етика» Спінози? Його
старший брат [spinoza](https://github.com/liberbook/simplex-bot-for-philosophy-circle) уміє все це на тій самій основі.

## Що він робить

У групі:

| що відбувається | що робить бот |
| --- | --- |
| хтось надсилає файл | мовчки завантажує його до архіву |
| хтось видаляє свій допис із файлом для всіх | переносить файл до `deleted/`, він стирається через 30 днів |
| `conatus` у відповідь на допис із файлом (або окремим словом одразу під ним) | повертає цей файл відповіддю |
| `/голосування Питання? \| Варіант 1 \| Варіант 2` | публікує одне повідомлення; голосують реакціями. Додайте `multiple`, щоб можна було обрати кілька варіантів |
| автор видаляє свій допис `/голосування` | голосування зникає разом із повідомленням бота |
| `/?` | коротка довідка відповіддю |

Слово `conatus` усередині речення, `голосування` без скісної риски й усе інше, що
кажуть люди, бот не чіпає: група — це розмова людей. На будь-яке особисте
повідомлення бот відповідає тією самою короткою довідкою.

Усе, що він каже, разом із повідомленням, яке це викликає, — у
[INTERFACE.md](INTERFACE.md) (генерується з коду, англійською). Нотатки про
безпеку: [SECURITY.md](SECURITY.md).

## Запуск

```bash
git clone https://github.com/liberbook/simplex-bot-for-reading-circle.git conatus && cd conatus/deploy
mkdir -p data && cp ../conatus.example.json data/conatus.json   # група, мова, ліміт, слово
docker compose up -d --build
docker compose logs -f        # адреса бота: `address: https://…` (також у data/state/address.txt)
```

Під'єднайтеся до цієї адреси із застосунку SimpleX і запросіть бота до своєї
групи. Він входить до будь-якої групи, чия назва відповідає `group` у
налаштуваннях (або заходить за посиланням із `groupLinks`). Ні адміністраторів, ні
секретів: хто може запросити бота, той і запрошує.

Щоб бот говорив українською, вкажіть `"language": "uk"` у `conatus.json`.

Без Docker:

```bash
simplex-chat -p 5225 -d ./db/chat --files-folder ./files --temp-folder ./tmp -y \
    --create-bot-display-name conatus --create-bot-allow-files
node src/main.js --group "Книжковий клуб"          # node src/main.js --help - усі налаштування
```

## Налаштування

`conatus.json` поруч із ботом (або `--config`), змінні середовища `CONATUS_*`,
прапорці командного рядка; пізніше джерело перемагає.

| ключ | за замовчуванням | значення |
| --- | --- | --- |
| `group` | `*` | які групи обслуговувати (`*` — будь-який текст) |
| `groupLinks` | `[]` | посилання на групи, до яких увійти під час запуску |
| `trigger` | `conatus` | слово, яким просять файл |
| `language` | `en` | `en`, `ru`, `uk`, `it` — мова всього, що каже бот |
| `maxStorage` | `100gb` | ліміт розміру архіву |
| `deletedRetentionDays` | `30` | скільки зберігати файли видалених дописів, `0` — завжди |
| `scan` | `100` | скільки останніх повідомлень перечитати під час запуску, щоб забрати пропущені файли |
| `server`, `dir`, `deletedDir`, `stateDir` | | адреса CLI та теки (у Docker задані) |

## Переклад

Кожен текст лежить у маленькому файлі на мову в [src/i18n/](src/i18n/), і це
просто дані — без коду й без знання про чат:

```js
noFileInPost: "There is no file in that post.",
whichFile: "Which file? Reply {trigger} to the post with the file.",
```

Щоб додати мову: скопіюйте [src/i18n/en.js](src/i18n/en.js), перекладіть
значення, імпортуйте файл у [src/i18n/languages.js](src/i18n/languages.js) і
додайте його до таблиці там само. Це все — `npm test` перевірить ваш файл на
пропущені ключі, зайві підстановки й командні слова, що не розпізнаються.

Учасники можуть писати команду **будь-якою** з мов, хоч якою б була мова групи:
`/vote`, `/sondaggio`, `/голосование` і `/голосування` відкривають голосування.

## Як він влаштований

```text
src/main.js               точка збирання: створює об'єкти, більше нічого
src/config.js             налаштування: за замовчуванням < файл < середовище < прапорці
src/transport/            протокол CLI: ChatConnection (WebSocket), SimplexClient (команди),
                          EventTranslator (JSON CLI -> події) - єдине місце з полями CLI
src/domain/Command.js     чого просить повідомлення в групі: /?, /vote, слово-тригер; решта - розмова
src/domain/Poll.js        голосування як дані: розбір, бюлетені, підрахунок
src/domain/Message.js     одне нормалізоване повідомлення
src/storage/Folder.js     тека файлів (архів, видалені): список, перенесення, очищення за віком
src/storage/Outbox.js     копії файлів, що надсилаються, щоб CLI не видалив оригінал з архіву
src/storage/PollStore.js  голосування в одному JSON-файлі
src/bot/Keeper.js         завантажує кожен файл, виносить файл видаленого допису, чистить
src/bot/Courier.js        повертає файл за словом-тригером
src/bot/Polls.js          голосування: повідомлення, реакції, видалення
src/bot/Helper.js         довідка
src/bot/Bot.js            спрямовує події, запускає все разом
src/i18n/                 кожен текст, по файлу на мову
```

Класи поведінки отримують шлюз і тексти через конструктор і не знають ні сокетів,
ні JSON; домен — чисті функції.

```bash
npm test                 # модульні тести, node:test, ~1 с (замість мережі - підробний шлюз)
npm run test:e2e         # увесь сценарій у Docker (~3 хв): власні релеї, троє користувачів, образ бота
npm run doc              # наново генерує INTERFACE.md з коду
```

## Дані

```text
deploy/data/files/       архів (він же тека файлів CLI)
deploy/data/deleted/     файли видалених дописів, 30 днів
deploy/data/state/       polls.json, address.txt
deploy/data/db/          база CLI: особа й ключі бота - не чіпати
```

Почати наново: `docker compose down && sudo rm -rf data/{db,files,deleted,state,tmp} && docker compose up -d`
(нова особа — бота доведеться запросити знову).
